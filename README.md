# Catapulta-de-birou
O catapultă complet funcțională de mărime mică cu un mecanism de reîncărcare.

Catapulta va imita, la o scară mai mică, modelul clasic cunoscut în media. Brațul va fi acționat de o pereche de arcuri de torsiune. 

Mecanismul de reîncărcare va consta într-un sistem de roți dințate, supradimensionat pentru scara modelului, care va trage capătul brațului corespunzător proiectilului la pământ, punându-l în tensiune. O piedică simplă va ține în loc brațul până în momentul catapultării.
